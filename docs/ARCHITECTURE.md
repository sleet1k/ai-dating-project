# 🏗️ АРХИТЕКТУРА ПРОЕКТА

## 🗺️ Общая схема

```
tg_client.py (CLI-оркестратор)
│
├── 🛠️  config/settings.py     — загрузка .env, Setup Wizard, парсинг ключей
├── 🤖  vlm_analyzer.py        — VLM-клиент, ротатор ключей, анализ анкет
├── ⚙️  engines/               — логика взаимодействия с ботами (Mamba, Lara и др.)
└── 📊  data/
    ├── history.md             — лог всех вердиктов
    ├── downloads/             — кеш скачанных фото
    ├── my_profile.json        — анкета пользователя для контекста VLM
    └── ai_agent_session       — сессия Telethon
```

---

## 🎛️ Двухуровневое CLI-меню (`tg_client.py`)

**Главное меню:**
```
1. 🚀 Запуск (Авто-режим)
2. ⚙️ Настройки
0. 🚪 Выход
```

**Подменю настроек:**
```
1. 🎯 Настройка критериев (ручная или через ✨ AI-адаптацию)
2. 🧠 Смена VLM-модели
3. 🔑 Управление GEMINI API-ключами (Ротатор)
4. 🧹 Очистка истории и кеша
5. 🧪 Тестовый анализ анкеты
6. 🛠️ Перепройти Setup Wizard
0. ⬅️ Назад
```

Никаких `argparse`-флагов — только интерактивное меню.

## 🤖 VLM Analyzer (`vlm_analyzer.py`)

### Инициализация
- При старте читает переменную `GEMINI_API_KEYS` (список ключей через запятую) или `GEMINI_API_KEY`.
- Создаёт глобальный `client = genai.Client(api_key=...)` с первым доступным ключом.

### Анализ анкеты (`analyze_profile`)
1. Один раз загружает и кешируует анкету пользователя из `data/my_profile.json`.
2. Один раз переводит `criteria.txt` на английский и кеширует в `translated_criteria_text`.
3. Строит системный промпт, при наличии прикрепляет изображение и вызывает Gemini API.
4. Возвращает JSON-объект `{"action": ..., "reason": ...}`.

### Режимы работы
| Режим | `action` | Применение |
|-------|----------|------------|
| `binary` | `"like"` / `"dislike"` | Классический свайп |
| `score` | `"1"`–`"10"` / `"skip"` | Рейтинговая оценка |

## 🔄 Ротатор API-ключей

При получении ошибки `429 (Resource Exhausted)` от Gemini:
1. Логируется предупреждение: `⚠️ Ключ AIzaSy... исчерпан (429), переключаюсь на следующий...`
2. `current_key_idx` инкрементируется по кольцу: `(idx + 1) % len(api_keys)`
3. Создаётся новый `genai.Client` с очередным ключом.
4. Запрос повторяется автоматически — пользователь ничего не замечает.

## 📡 Интеграция с Telethon

- Сессия хранится в `data/ai_agent_session` (SQLite-файл Telethon).
- Директория `data/` создаётся автоматически перед инициализацией, чтобы избежать `sqlite3.OperationalError`.
- Основной цикл перебирает сервисы, вызывает `process_dating_bot`, а тот — `analyze_profile`.

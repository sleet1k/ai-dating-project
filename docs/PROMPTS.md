# 🧠 ПРОМПТЫ И AI-ГЕНЕРАЦИЯ КРИТЕРИЕВ

## 📐 Системный промпт для анализа анкет

VLM получает **системную инструкцию**, которая задаёт роль и правила поведения:

```
Role: Strict dating profile evaluator.
Rules: Evaluate target photo and bio based on user criteria and my_profile context.
Output: Response MUST be a valid JSON object matching the requested schema. Reason MUST be concise (under 15 words).
```

Промпт собирается динамически из трёх частей:
1. **Анкета пользователя** — загружается один раз из `data/my_profile.json` и вставляется в инструкцию как контекст.
2. **Переведённые критерии** — английская версия `criteria.txt`, кешированная в `translated_criteria_text`.
3. **Входящий профиль** — текст анкеты кандидата и (опционально) прикреплённое фото.

## 🔀 Режимы анализа

### Режим `binary` — лайк/дизлайк
Применяется по умолчанию. Возвращает строгое решение:
```json
{"action": "like", "reason": "Симпатичная, интересы совпадают"}
{"action": "dislike", "reason": "Возраст не подходит, пустая анкета"}
```

### Режим `score` — числовая оценка
Применяется в ботах с рейтинговым свайпом:
```json
{"action": "8", "reason": "Хороший вайб, активный профиль"}
{"action": "skip", "reason": "Рекламный аккаунт, ссылки в описании"}
```

| Значение | Смысл |
|----------|-------|
| `"skip"` | Токсичный профиль / возраст < 16 / спам |
| `"1"`–`"5"` | Неинтересная анкета, низкая совместимость |
| `"6"`–`"8"` | Нормальный профиль, приемлемо |
| `"9"`–`"10"` | Отличная анкета, высокая совместимость |

## ✨ Функция «Улучшить вкус» (AI-адаптация критериев)

При выборе **Настройки → Настройка критериев → ✨ Улучшить вкус**:

1. Пользователь вводит пожелания произвольным языком, например:
   > *«хочу junior разработчицу, чтобы играла в доту и любила котов»*

2. Текст отправляется в Gemini (`gemini-3.5-flash`) с системным промптом:
   ```
   Преобразуй пользовательский список пожеланий к кандидату в четкие, структурированные
   критерии оценки для VLM на русском языке. Только текст критериев, без вступления.
   ```

3. Модель возвращает структурированный список, примерно такой:
   ```
   Возраст: от 20 до 28 лет.
   Профессия: предпочтительно IT, разработка.
   Интересы: плюсом видеоигры (особенно Dota 2), любовь к животным.
   Красные флаги (сразу SKIP): агрессия, пустые анкеты, поиск спонсора.
   ```

4. Результат выводится на экран. При подтверждении — перезаписывает `criteria.txt` и немедленно переводит критерии в `translated_criteria_text`. VLM начинает использовать их на следующей же анкете.

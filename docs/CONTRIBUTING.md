# 🤝 КАК ВНЕСТИ ВКЛАД В ПРОЕКТ

Мы рады любым пулл-реквестам, идеям и буг-репортам. Вот как правильно влиться в разработку:

## 🚀 Быстрый старт

1. **Форкни репозиторий** и клонируй к себе:
   ```bash
   git clone https://github.com/ВАШ_НИК/ai-dating-project
   cd ai-dating-project
   ```

2. **Создай виртуальное окружение** и установи зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Запусти проект** и убедись, что всё работает:
   ```bash
   python tg_client.py
   ```

---

## 🌿 Процесс работы с кодом

1. Создай ветку с понятным именем:
   ```bash
   git checkout -b feature/my-cool-feature
   # или
   git checkout -b fix/broken-something
   ```

2. Внеси изменения, соблюдая стилистику (см. ниже).

3. Сделай коммит с понятным сообщением:
   ```bash
   git commit -m "feat: добавил авто-реплай после мэтча"
   ```

4. Запушь ветку и открой **Pull Request** в `main`.

---

## 🎨 Стиль кода

- Отступы: **4 пробела**, не табы.
- Длина строки: не более **120 символов**.
- Типизация: используй **type hints** для публичных функций.
- Докстринги: пиши для всех новых функций и классов.
- Логи: используй цветовые коды `\033[9Xm` в стиле остального CLI.

# 🗺️ ROADMAP — ВЕКТОР РАЗВИТИЯ

## ✅ Уже реализовано

| Фича | Описание |
|------|----------|
| 🎛️ **Двухуровневое CLI-меню** | Главное меню + подменю настроек, ноль argparse-флагов |
| 🔄 **Авто-ротатор API-ключей** | Бесшовное переключение при ошибке `429 (Resource Exhausted)` |
| ✨ **«Улучшить вкус» (AI-критерии)** | Генерация системного промпта из бытового описания через Gemini |
| 🎯 **Динамические критерии (`criteria.txt`)** | Хранение критериев на русском + авто-перевод через `deep-translator` |
| 🧹 **Умная очистка кеша и истории** | Удаление `history.md` и `data/downloads` прямо из меню |
| 🛠️ **Setup Wizard** | Интерактивная настройка `.env` при первом запуске |
| 🔐 **Авто-создание директорий** | `data/` создаётся до инициализации сессии Telethon |
| 🧠 **Поддержка нескольких VLM-моделей** | Переключение между Gemini Flash/Flash-Lite прямо из CLI |
